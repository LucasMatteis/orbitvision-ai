# OrbitVision AI

## Descrição

OrbitVision AI é uma aplicação desenvolvida para auxiliar no monitoramento ambiental através da análise de imagens de satélite utilizando técnicas de Processamento Digital de Imagens e Machine Learning.

O sistema classifica automaticamente imagens em três categorias:

* Floresta Preservada
* Área Queimada
* Área Desmatada

## Tecnologias Utilizadas

* Python
* Flask
* OpenCV
* Scikit-Learn
* NumPy
* Joblib

## Funcionalidades

* Upload de imagens
* Processamento digital de imagens
* Classificação automática utilizando Machine Learning
* Exibição de nível de risco ambiental
* Recomendações automáticas

## Como executar

Instalar dependências:

pip install -r requirements.txt

Executar aplicação:

python app.py

Acessar:

http://127.0.0.1:5000

## Objetivo

Demonstrar como imagens de satélite podem ser utilizadas para monitoramento ambiental, contribuindo para ações de preservação e prevenção de impactos ambientais.
